# Security policy

Report a vulnerability through GitHub's private vulnerability reporting. Open this repository's
**Security** tab and choose **Report a vulnerability**. Don't open a public issue for a
vulnerability.

If you can't use GitHub, email `security@beacons.gg`. Reports about Beacon's hosted service go to
the same address.

Only the latest release of the `@beaconsgg/*` packages gets security fixes.

The maintainers acknowledge a report within 3 business days.

This file follows the
[security policy of the Beacon organization](https://github.com/beacons-gg/.github/blob/main/SECURITY.md),
which covers every Beacon repository.
